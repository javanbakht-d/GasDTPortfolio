# ماتریس نقش‌ها و مجوزها (RBAC Matrix) — NIGC-DTG

## اصول

1. **رد پیش‌فرض**: هیچ دسترسی بدون تخصیص صریح نقش/مجوز وجود ندارد.
2. **اجرای سمت سرور**: مجوزها در تمام مسیرهای API با `requireAuth` + `requirePerm` بررسی می‌شوند؛ پنهان‌کردن منو در رابط کاربری فقط برای تجربه کاربری است، نه کنترل امنیتی.
3. **محدوده سازمانی**: کاربران واحد فقط داده‌های واحد خود را می‌بینند؛ نقش‌های «نمای کلان» (GLOBAL_VIEW_ROLES) دبیرخانه/شورا/مدیریت سامانه کل داده را می‌بینند.
4. **قابل تنظیم از پنل مدیریت**: نقش‌ها و ترکیب مجوزها از پنل مدیریت قابل تغییر است؛ نقش‌های پیش‌فرض، «انتصاب سازمانی» تلقی نمی‌شوند.

## قواعد تفکیک تأیید

- تأیید نهایی اقدام/سند/پروژه از نقش‌های «تأیید» (دبیرخانه، شورا، REVIEWER) برمی‌آید و پیکربندی آن قابل ویرایش است.
- کاربر غیرفعال‌شده: تمام نشست‌های معتبر وی در لحظه ابطال می‌شوند (جدول Session) و ورود مجدد مسدود می‌شود.
- عملیات حساس (تغییر تاریخ مبنا، تغییر نقش‌ها، تغییر پیکربندی) با مجوز `sensitive_ops` / `settings:manage` و ثبت در سوابق ممیزی انجام می‌شود.
