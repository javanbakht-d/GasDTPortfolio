# برنامه آزمون و معیارهای پذیرش — NIGC-DTG

## چارچوب اجرای آزمون در این محیط

در محیط سندباکس فعلی، اجرای مجموعه آزمون‌های خودکار کامل (unit/E2E CI) مهیا نیست؛ به‌جای آن:
- **آزمون دستی ارکستر‌شده با مرورگر (Agent Browser)** روی مسیرهای طلایی انجام شد.
- **Lint** (`bun run lint`) اجرا و خطاها صفر شد.
- سوابق آزمون در این سند ثبت می‌شود. ساخت آزمون‌های خودکار (Vitest/Playwright) به‌عنوان قدم توسعه بعدی در `roadmap` پروژه است.

## آزمون‌های آینده (قبل از استقرار عملیاتی)

1. آزمون خودکار RBAC برای همه نقش‌ها × همه مسیرهای API.
2. آزمون E2E گردش کار کامل (ایجاد اقدام جدید → بررسی → تأیید → بستن).
3. آزمون بار محدود برای مسیرهای گزارش‌گیری.
4. آزمون بازیابی پشتیبان پایگاه داده.
