# ماتریس ردیابی نیازمندی‌ها — NIGC-DTG

**هدف:** اتصال سه‌سویه «منبع (پرامپت جامع / سند مرجع ۳۷ گامی) ← نیازمندی (FR/NFR در requirements.md) ← قابلیت پیاده‌شده (ماژول + API)» به‌گونه‌ای که هیچ تکلیف سند مرجع در سامانه گم نشود (الزام §۲.۱ پرامپت و §۲۰ پذیرش کارکردی بند ۱).

**قرارداد منابع:**
- `§n` = بخش n از پرامپت جامع (۲۳ بخش).
- `گام n` = گام n از برنامه اقدام دبیرخانه (refStep = n).
- `جدول n سند` / `فصل n سند ابلاغی` / `محور ۶-x سند ابلاغی` = ارجاع‌های درون سند مرجع به برنامه اجرایی نسخه ۲٫۰.
- APIها تحت `src/app/api/*` و ماژول‌ها روی مسیر واحد `/` (محدودیت sandbox).
