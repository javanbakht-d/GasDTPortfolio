# NIGC-DTG — سامانه راهبری تحول دیجیتال، حاکمیت داده و هوش مصنوعی

**پورتفولیوی یکپارچه شرکت ملی گاز ایران (NIGC)** — ناوبری اجرایی کامل برنامه تحول دیجیتال، حاکمیت داده و هوش مصنوعی با رابط راست‌به‌چپ فارسی.

**طراح و معمار:** داود جوانبخت — معاون مطالعات آینده‌پژوهی و آینده‌نگاری و دبیر شورای راهبری تحول دیجیتال و حکمرانی هوشمند شرکت ملی گاز ایران

## قابلیت‌های کلیدی

- **۱۷ ماژول عملیاتی** — داشبورد، اقدامات (۳۷ گام سند ابلاغی با ردیابی منبع)، اسناد، پروژه‌ها، حاکمیت داده، دفتر هوش مصنوعی، KPI، ریسک، انحراف، جلسات، مصوبات، بودجه، گزارش‌ها، چارت سازمانی، دانش‌نامه، هوش مصنوعی، پایش
- **۱۶ نقش RBAC** با ماتریس مجوز و تفکیک کامل سطوح دسترسی
- **میز کار روزانه دبیر** — خلاصه اجرایی، اقدامات نیازمند توجه، تعهدات در خطر، انتظارات از دیگران
- **موتور یادآور سروری** — مستقل از مرورگر کاربر، با صف اعلان، ضدتکرار، ساعات سکوت و پنل سلامت
- **دستیار هوشمند مبتنی بر واقعیت** — پاسخ با استناد به شناسه رکوردها (قابل غیرفعال‌سازی بدون آسیب به هسته)
- **رد ممیزی کامل** — تمام کنش‌های حساس ثبت و قابل جستجو است
- **۱۲ سند طراحی و عملیاتی** در پوشه `docs/`

## استک فناوری

Next.js 16 (App Router) · TypeScript · Tailwind CSS 4 · shadcn/ui · Prisma · SQLite (لوکال) / PostgreSQL (ابر) · bcryptjs + نشست دیتابیسی

## اجرای لوکال

```bash
cp .env.example .env        # DATABASE_URL پیش‌فرض SQLite
bun install
bun run db:push             # ساخت جداول
bun scripts/seed.ts         # داده‌های اولیه (۳۷ گام، نقش‌ها، کاربران نمونه)
bun run dev                 # http://localhost:3000
```

کاربران نمونه (پس از seed): `admin` — رمز: `Nigc@1405` (بلافاصله تغییر دهید)

## استقرار رایگان ابری (Vercel + Neon)

راهنمای کامل گام‌به‌گام: **[docs/deploy-guide.md](docs/deploy-guide.md)**

خلاصه معماری ابری:

| جزء | سرویس | پلن |
|---|---|---|
| اپلیکیشن | Vercel | Hobby (رایگان) |
| دیتابیس | Neon PostgreSQL | Free (۰٫۵ گیگابایت) |
| زمان‌بند یادآور | cron-job.org → `/api/system/cron-tick` | رایگان (هر ۵ دقیقه) |
| راه‌اندازی اولیه | `/api/system/bootstrap` با `BOOTSTRAP_TOKEN` — بدون نیاز به ابزار لوکال | — |

## مستندات

`docs/` — وضعیت موجود (audit)، موتور یادآور، قابلیت‌های دستیار، ماتریس RBAC، مدل تهدید، برنامه آزمون، بررسی UX، امنیت، آزمون‌های پذیرش، یادداشت انتشار، راهنمای عملیات، مفروضات و تصمیم‌های باز، راهنمای استقرار ابری.
